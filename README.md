# Lionel Messi Tribute Page

A static, responsive, single-page tribute to Lionel Messi, built for Task 1 (Tribute Page) of my Web Development internship.

**Live page:** YOUR_GITHUB_PAGES_LINK_HERE

## About the project

The page celebrates Messi's life and career. It has an image, a headline, a short biography, a list of achievements, and a timeline of key moments from 1987 to 2023.

## Objective

To practice semantic HTML, basic page structure, and introductory CSS styling.

## Tools used

- HTML5
- CSS3
- VS Code
- Git and GitHub (free)

## My approach

1. **Planning:** I chose the person, then collected a photo, a biography, achievements, and timeline events before writing any code.
2. **Semantic HTML:** I structured the page with `header`, `main`, `section`, `figure`, `figcaption`, and `footer` so the content has meaning and is easier for screen readers and search engines to understand.
3. **CSS styling:** I used a reset, a readable font and line height, and styled the timeline with a simple left border. I used `class` for styles that repeat and `id` for unique sections.
4. **Readable layout:** I put the content in a container with `max-width: 800px`, centered with `margin: 0 auto`, so the text stays readable on large screens.
5. **Responsive design:** The image uses `max-width: 100%` and `height: auto`, and a media query for screens of 600px and below reduces font sizes and padding on mobile.
6. **Testing:** I resized the browser and used the browser's mobile view to check that nothing scrolls sideways and the text stays readable.
